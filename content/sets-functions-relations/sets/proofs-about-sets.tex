\olsection{关于集合的证明}

\begin{editorial}
本节已被 \verb|content/method/proofs| 替代，并已默认从本章移除。
\end{editorial}

\begin{explain}
集合以及我们迄今引入的记号，为我们指定集合和表达集合之间的关系提供了简便的缩写。通常，我们还需要证明有关这些关系的断言。如果你不熟悉数学证明，这可能对你来说还很陌生。所以我们将通过一个简单的例子来逐步说明。我们将证明，对任意集合 $X$ 和 $Y$，总有 $X \cap (X \cup Y) = X$。如何证明像这样的集合恒等式呢？回想一下，集合完全由其元素决定，即，两个集合相等当且仅当它们具有相同的元素。所以在这种情况下，我们必须证明 $X \cap (X \cup Y)$ 的每个元素也是 $X$ 的元素，反之，$X$ 的每个元素也是 $X \cap (X \cup Y)$ 的元素。换句话说，我们要证明 $X \cap (X \cup Y) \subseteq X$ 且 $X \subseteq X \cap (X \cup Y)$。

要证明“$X \cap (X \cup Y)$ 的每个元素~$z$ 也是 $X$ 的元素”这样的全称断言，方法是：先假设给定任意的 $z \in X \cap (X \cup Y)$，然后从该假设出发证明 $z \in X$。你可能知道这种模式被称为“一般条件句证明”。在这个证明中，我们还需要用到假设和结论中涉及的定义，例如本例中的“$\cap$”和“$\cup$”。因此，(a) 部分的论证如下：

\begin{quote}
(a) 我们首先想证明 $X \cap (X \cup Y) \subseteq X$，即根据 $\subseteq$ 的定义，对任意~$z$，如果 $z \in X \cap (X \cup Y)$ 那么 $z \in X$。所以假设 $z \in X \cap (X \cup Y)$。因为一个元素属于两个集合的交集，当且仅当它同时属于这两个集合，所以我们可以得出结论：$z \in X$ 并且 $z \in X \cup Y$。特别地，$z \in X$，这正是我们要证明的。
\end{quote}

这就完成了证明的前一半。注意，在最后一步我们用到了这样一个事实：如果一个合取式（$z \in X$ 且 $z \in X \cup Y$）可以从一个假设推出，那么每个合取支也可以从同一个假设推出。你可能知道这条规则叫“合取消去”，或 $\land$Elim。现在我们来证明 (b)：

\begin{quote}
(b) 我们现在证明 $X \subseteq X \cap (X \cup Y)$，即根据 $\subseteq$ 的定义，对任意~$z$，如果 $z \in X$ 那么也有 $z \in X \cap (X \cup Y)$。假设 $z \in X$。为了证明 $z \in X \cap (X \cup Y)$，我们需要证明（根据“$\cap$”的定义） (i) $z \in X$ 并且 (ii) $z \in X \cup Y$。这里的 (i) 正是我们的假设，所以无需再证。对于 (ii)，回想一下，一个元素属于若干集合的并集，当且仅当它至少属于这些集合中的一个。既然 $z \in X$，而 $X \cup Y$ 是 $X$ 和 $Y$ 的并集，因此这一条件成立。于是 $z \in X \cup Y$。我们已经证明了 (i) $z \in X$ 和 (ii) $z \in X \cup Y$，从而根据“$\cap$”的定义，$z \in X \cap (X \cup Y)$。
\end{quote}

这有些冗长，但它展示了我们如何对集合及其关系进行推理。通常我们不会这么详细；特别是，我们可能不会重复所有的定义。在更高级的教材中，这个结果的证明会被压缩得多。它可能看起来像下面这样。
\end{explain}


\begin{prop}[吸收律]
对所有集合 $X$, $Y$，
\[
X \cap (X \cup Y) = X
\]
\end{prop}

\begin{proof}
(a) 假设 $z \in X \cap (X \cup Y)$。则 $z \in X$，故 $X \cap (X \cup Y) \subseteq X$。

(b) 现设 $z \in X$。则 $z \in X \cup Y$，从而 $z \in X \cap (X \cup Y)$。于是，$X \subseteq X \cap (X \cup Y)$。
\end{proof}

详细证明 $X \cup (X \cap Y) = X$。然后给出一个精简的证明。（提示：对于 $X \cup (X \cap Y) \subseteq X$ 的方向，需要用到分情况证明，即析取消去。）
\end{prob}
