\olpart{fol}{一阶逻辑}

\begin{editorial}
  本部分涵盖一阶逻辑的元理论，直至完备性定理。
  目前，本部分不依赖对命题逻辑的单独处理，所有结论均给出证明。
  若 `FOL` 标签为假，源文件将排除关于量词的材料（并将“结构”替换为“赋值”，将 $\Struct{M}$ 替换为 $\pAssign{v}$ 等）。
  事实上，命题逻辑部分的大部分材料，就是关闭 `FOL` 标签后的一阶逻辑材料。

  若将命题逻辑部分也包含在内，则会导致大量重复。
  不过，我们计划在未来做出调整，使本部分能够兼顾命题逻辑部分的材料（从而排除已涵盖的内容，并通过引用命题逻辑部分对应位置的内容来缩短证明）。
\end{editorial}
