\olsection{将推导转换为证明项}

将自然演绎推导转换为证明项的过程（即将~\Log{N2i} 中的推导翻译为~\Log{tN2i} 中的推导）是非常直接的。
它只需在推导的相继式中，为右侧每个公式的左边写上一个证明项，从而得到形如 $\Gamma \Sequent M :
!A$ 的相继式。 我们此后便称，$M$ 在上下文~$\Gamma$ 中\emph{见证}了~$!A$。
具体写哪个证明项，完全由 \Log{tN2i} 的规则决定。

\begin{prop}
对于 \Log{N2i} 中每个 $\Gamma \Sequent !A$ 的推导~$\delta$，
都对应于 \Log{tN2i} 中一个 $\Gamma \Sequent N : !A$ 的推导~$\delta'$。
该证明项 $N$ 由~$\delta$ 唯一确定。
\end{prop}

\begin{proof}
我们对~$\delta$ 的高度进行归纳。如果 $\delta$ 是公理 $x:!A \Sequent !A$，
那么 $\delta'$ 就是公理~$x:!A \Sequent x:!A$。
如果 $\delta$ 以某条推理规则结束，
根据归纳假设，每个前提都有相应的证明项，并且存在包含这些证明项的相继式的 \Log{tN2i} 推导。
我们应用 \Log{tN2i} 的相应规则；相应的证明项则由该 \Log{tN2i} 推理规则确定。
\end{proof}

\begin{ex}
  考虑 \Log{N1i} 中一个非常简单的推导 $(!A \land !B)
  \lif (!B \land !A)$：
  \[
  \AxiomC{$\Discharge{!A\land !B}{x}$}
  \RightLabel{\Elim\land[2]}
  \UnaryInfC{$!B$}
  \AxiomC{$\Discharge{!A\land !B}{x}$}
  \RightLabel{\Elim\land[1]}
  \UnaryInfC{$!A$}
  \RightLabel{\Intro\land}
  \BinaryInfC{$!B \land !A$}
  \DischargeRule{\Intro\lif}{x}
  \UnaryInfC{$(!A \land !B) \lif (!B \land !A)$}
  \DisplayProof
  \]
  在 \Log{N2i} 中，它如下所示：
  \[
  \Axiom$x : !A\land !B \fCenter !A\land !B$
  \RightLabel{\Elim\land[2]}
  \UnaryInf$x : !A\land !B \fCenter !B$
  \Axiom$x : !A\land !B \fCenter !A\land !B$
  \RightLabel{\Elim\land[1]}
  \UnaryInf$x : !A\land !B \fCenter !A$
  \RightLabel{\Intro\land}
  \BinaryInf$x : !A\land !B \fCenter !B \land !A$
  \RightLabel{\Intro\lif}
  \UnaryInf$\fCenter (!A \land !B) \lif (!B \land !A)$
  \DisplayProof
  \]
  我们从上至下分配证明项。公理的证明项就是上下文中的同名变元，即~$x$。
  于是，与 $\Elim\land[i]$ 规则关联的证明项就确定为 $\proj{2}{x}$ 和~$\proj{1}{x}$。
  当我们应用 \Intro{\land} 规则时，将这两个证明项组合起来：$\pair{\proj{2}{x}}{\proj{1}{x}}$。
  最后，\Intro{\lif} 规则应用了一个 $\lambd$-抽象，绑定~$x$ 并记录 $x$ 标注了假设~$!A \land
  !B$：$\lambd[\typeof{x}{!A \land
  !B}][\pair{\proj{2}{x}}{\proj{1}{x}}]$。
  因此，\Log{tN2i} 中的推导就是：
  \[
  \Axiom$x : !A\land !B \fCenter x: !A\land !B$
  \RightLabel{\Elim\land[2]}
  \UnaryInf$x : !A\land !B \fCenter \proj{2}{x} : !B$
  \Axiom$x : !A\land !B \fCenter x: !A\land !B$
  \RightLabel{\Elim\land[1]}
  \UnaryInf$x : !A\land !B \fCenter \proj{1}{x} : !A$
  \RightLabel{\Intro\land}
  \BinaryInf$x : !A\land !B \fCenter \pair{\proj{2}{x}}{\proj{1}{x}} :
    !B \land !A$
  \RightLabel{\Intro\lif}
  \UnaryInf$\fCenter \lambd[\typeof{x}{!A \land
  !B}][\pair{\proj{2}{x}}{\proj{1}{x}}] : (!A \land !B) \lif (!B \land !A)$
  \DisplayProof
  \]
\end{ex}
