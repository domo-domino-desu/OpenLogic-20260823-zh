\chapter*{关于 Open Logic Project}
\addcontentsline{toc}{chapter}{关于 Open Logic Project}

\textit{Open Logic Text}是一本开源协作的形式元逻辑与形式化方法教科书，以中级水平为起点（即修完一门形式逻辑导论课程之后）。本书虽主要面向非数学背景的读者（特别是哲学和计算机科学专业的学生），但论述严谨。

目前已收录的某些主题可能尚未涵盖完全，许多章节也仍需大幅修订。我们计划在未来扩充教材内容，涵盖更多主题。我们还计划为教材添加一些特性，例如词汇表、拓展阅读书目、历史注记、插图、更好的讲解、阐释这些结果与哲学、计算机科学及数学有何关联的章节，以及更多的习题与示例。如果您发现错误或有任何建议，\href{https://github.com/OpenLogicProject/OpenLogic/wiki/Contributing}{请告知项目团队}。

本项目以开源精神运作。本教材不仅可免费获取，我们还按照知识共享署名许可协议提供其 \LaTeX{} 源代码；该协议赋予任何人下载、使用、修改、重新编排、转换及再分发我们作品的权利，前提是给予适当署名。更多信息请访问Open Logic Project 网站 \href{http://openlogicproject.org/}{openlogicproject.org}。
