\olsection{滤过与可达关系的性质}

如前所述，全称模型、序列模型、自反模型的滤过也总是全称、序列或自反的。但对称模型或传递模型的滤过却未必分别是对称的或传递的。不过在某些情形下，我们确实可以把滤过定义成使这条性质成立。为此，我们仿照最粗滤过的定义那样进行，只是在~$R^*$ 的定义里再加上一些额外条件。设 $\Gamma$ 对子公式封闭。考虑模型 $\mModel{M} =\tuple{W, R, V}$ 中世界 $u$、$v$ 之间、在 \olref{tab:Cn-filtrations} 里给出的那些关系~$C_i(u,v)$。我们可以在这些条件的各种组合的基础上定义 $R^*[u][v]$。举例来说，如果我们规定 $R^*[u][v]$ 当且仅当条件 $C_1(u,v)$ 成立，得到的恰好就是最粗滤过。如果我们规定 $R^*[u][v]$ 当且仅当 $C_1(u,v)$ 和 $C_2(u, v)$ 都成立，就会得到一个不同的滤过。它比最粗滤过"更细"，因为同时满足 $C_1(u,v)$ 和 $C_2(u,v)$ 的世界对，比只满足 $C_1(u,v)$ 的世界对要少。

\begin{thm}\ollabel{thm:more-filtrations}
  设 $\mModel{M} =\tuple{W,R,V}$ 是一个模型，$\Gamma$ 对子公式封闭。设 $W^*$ 和 $V^*$
  按 \olref[fil]{defn:filtration} 中的定义给出。则：
  \begin{enumerate}
  \item 设 $R^*[u][v]$ 当且仅当 $C_1(u, v) \land
    C_2(u,v)$。则 $R^*$ 是对称的，且当 $\mModel{M}$ 是对称的时候，$\mModel{M^*} =
    \tuple{W^*,R^*,V^*}$ 是一个滤过。
  \item 设 $R^*[u][v]$ 当且仅当 $C_1(u, v)
    \land C_3(u,v)$。则 $R^*$ 是传递的，且当 $\mModel{M}$
    是传递的时候，$\mModel{M^*}=\tuple{W^*,R^*,V^*}$ 是一个滤过。
  \item 设 $R^*[u][v]$ 当且仅当 $C_1(u, v) \land C_2(u,v)
    \land C_3(u,v) \land C_4(u,v)$。则 $R^*$ 是对称且传递的，且当 $\mModel{M}$
    是对称且传递的时候，$\mModel{M^*}=\tuple{W^*,R^*,V^*}$ 是一个滤过。
  \item 设 $R^*$ 定义为：$R^*[u][v]$ 当且仅当 $C_1(u,
    v) \land C_3(u,v) \land C_4(u,v)$。则 $R^*$ 是传递且欧几里得的，且当 $\mModel{M}$
    是传递且欧几里得的时候，$\mModel{M^*}=\tuple{W^*,R^*,V^*}$ 是一个滤过。
  \end{enumerate}
\end{thm}

  \begin{enumerate}
    \item $R^*$ 是对称的这一点是显然的，因为 $C_1(u,v)
      \Leftrightarrow C_2(v,u)$ 且 $C_2(u,v) \Leftrightarrow
      C_1(v,u)$。所以剩下要证明的是：若 $\mModel{M}$ 是
      对称的，则 $\mModel{M^*}$ 是通过~$\Gamma$ 的一个滤过。条件 $C_1(u,v)$ 保证了
      \iftag{prvBox}{%

          \olref[fil]{defn:filtration} 的
          \olref[fil]{defn:filtration-R2} 和
          \olref[fil]{defn:filtration-R3} 都}{%
          \olref[fil]{defn:filtration}\olref[fil]{defn:filtration-R2} }}{%
        \olref[fil]{defn:filtration}\olref[fil]{defn:filtration-R3} }
      得到满足。所以我们只需验证
      \olref[fil]{defn:filtration}\olref[fil]{defn:filtration-R1}，
      即证明 $Ruv$ 蕴涵 $R^*[u][v]$。

      于是设 $Ruv$。要证明 $R^*[u][v]$，我们需要证明
      $C_1(u,v)$ 和 $C_2(u,v)$ 都成立。对于 $C_1$：\iftag{prvBox}{若 $\Box!A
        \in\Gamma$ 且 $\mSat{M}{\Box!A}[u]$，则由 $Ruv$ 也有
        $\mSat{M}{!A}[v]$。\iftag{prvDiamond}{ 类似地，
        }{}}{}\iftag{prvDiamond}{若 $\Diamond!A \in \Gamma$ 且
        $\mSat{M}{!A}[v]$，则由
        $Ruv$ 有 $\mSat{M}{\Diamond!A}[u]$。}{} 对于 $C_2$：\iftag{prvBox}{若 $\Box!A \in \Gamma$ 且
        $\mSat{M}{\Box!A}[v]$，则由对称性 $Ruv$ 蕴涵 $Rvu$，从而
        $\mSat{M}{!A}[u]$。\iftag{prvDiamond}{ 类似地，
        }{}}{}\iftag{prvDiamond}{若 $\Diamond!A \in\Gamma$ 且
        $\mSat{M}{!A}[u]$，则 $\mSat{M}{\Diamond!A}[v]$（由对称性 $Rvu$
        成立）。}{}

\end{proof}
