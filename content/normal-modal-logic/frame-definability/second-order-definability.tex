\olsection{二阶可定义性}

并非所有模态公式可定义的框架性质都是一阶可定义的。
然而，如果我们允许对一元谓词进行量化（即一元二阶量化），
就能定义所有模态可定义的框架性质。
其技巧在于利用一种系统化的方式，将模态公式在世界中为真的条件同一阶公式关联起来。
这就是所谓的模态公式到一阶公式的\emph{标准翻译}，其中目标语言不仅包含表示可达关系的二元谓词符号~$Q$，
还包含对应于~$!A$ 中出现的命题变元~$\Obj p_i$ 的一元谓词符号~$P_i$。

\begin{defn}
  \emph{标准翻译}~$\ST_x(!A)$ 归纳定义如下：
  \begin{enumerate}
  \tagitem{prvFalse}{\indcase{!A}{\lfalse}{$\ST_x(\indfrm) = \lfalse$.}}{}
  \tagitem{prvTrue}{\indcase{!A}{\lfalse}{$\ST_x(\indfrm) = \ltrue$.}}{}
  \item \indcase{!A}{\Obj p_i}{$\ST_x(\indfrm) = \Atom{P_i}{x}$.}
  \tagitem{prvNot}{\indcase{!A}{\lnot !B}{$\ST_x(\indfrm) = \lnot \ST_x(!B)$.}}{}
  \tagitem{prvAnd}{\indcase{!A}{(!B \land !C)}{$\ST_x(\indfrm) = (\ST_x(!B)
      \land \ST_x(!C))$.}}{}
  \tagitem{prvOr}{\indcase{!A}{(!B \lor !C)}{$\ST_x(\indfrm) = (\ST_x(!B)
      \lor \ST_x(!C))$.}}{}
  \tagitem{prvIf}{\indcase{!A}{(!B \lif !C)}{$\ST_x(\indfrm) = (\ST_x(!B)
      \lif \ST_x(!C))$.}}{}
  \tagitem{prvIff}{\indcase{!A}{(!B \liff !C)}{$\ST_x(\indfrm) = (\ST_x(!B)
      \liff \ST_x(!C))$.}}{}
  \tagitem{prvBox}{\indcase{!A}{\Box !B}{$\ST_x(\indfrm) =
      \lforall[y][(\Atom{Q}{x,y} \lif \ST_y(!B))]$.}}{}
  \tagitem{prvDiamond}{\indcase{!A}{\Diamond !B}{$\ST_x(\indfrm) =
      \lexists[y][(\Atom{Q}{x,y} \land \ST_y(!B))]$.}}{}
  \end{enumerate}
\end{defn}

例如，$\ST_x(\Box p \lif p)$ 是 $\lforall[y][(\Atom{Q}{x,y}
  \lif \Atom{P}{y})] \lif \Atom{P}{x}$。语言~$\ST_x(!A)$ 的任何结构都必须包含一个论域、
一个指派给~$Q$ 的二元关系，以及指派给一元谓词符号~$P_i$ 的论域子集。
换句话说，这种结构的组成部分恰好就是~$!A$ 的模型的组成部分：论域是世界集，
指派给~$Q$ 的二元关系是可达关系，而指派给~$P_i$ 的子集正是赋值~$V(\Obj p_i)$。
毫不令人意外的是，$!A$ 在模态模型中被满足，当且仅当 $\ST_x(!A)$ 在对应结构中被满足：

\begin{prop}\ollabel{prop:st}
  令 $\mModel{M} = \tuple{W, R, V}$，$\Struct{M'}$ 为满足 $\Domain{M'} = W$、$\Assign{Q}{M'} = R$
  和 $\Assign{P_i}{M'} = V(\Obj p_i)$ 的一阶结构，并设 $s(x) = w$。则
  \[
  \mSat{M}{!A}[w] \text{ 当且仅当 } \Sat{M'}{\ST_x(!A)}[s]
  \]
\end{prop}

\begin{proof}
  对~$!A$ 进行归纳。
\end{proof}

\begin{prop}
  设 $!A$ 为模态公式，且 $\mModel{F} = \tuple{W, R}$
  为框架。令 $\Struct{F'}$ 为满足
  $\Domain{F'} = W$ 且 $\Assign{Q}{F'} = R$ 的一阶结构，并令 $!A'$ 为二阶公式
  \[
  \lforall[X_1][\dots\lforall[X_n][\lforall[x][
        \SSubst{\ST_x(!A)}{\subst{X_1}{P_1}, \dots,
          \subst{X_n}{P_n}}]]],
  \]
  其中 $P_1$, \dots, $P_n$ 是~$\ST_x(!A)$ 中出现的所有一元谓词符号。
  则
  \[
  \mModel{F} \Entails !A \text{ 当且仅当 } \Sat{F'}{!A'}
  \]
\end{prop}

\begin{proof}
  $\Sat{F'}{!A'}$ 当且仅当对于每个满足 $\Assign{P_i}{M'} \subseteq W$（对 $i = 1$, \dots,~$n$）的结构~$\mModel{M'}$，
  以及每个满足 $s(x) \in W$ 的 $s$，都有 $\Sat{M'}{\ST_x(!A)}[s]$。根据
  \olref{prop:st}，这成立当且仅当对于所有基于~$\mModel{F}$ 的模型~$\mModel{M}$ 和每个世界~$w \in W$，
  都有 $\mSat{M}{!A}[w]$，即 $\mModel{F} \Entails !A$。
\end{proof}

\begin{defn}
  框架类~$\mClass{F}$ 是\emph{二阶可定义的}，如果
  存在二阶语言中的一个语句~$!A$，该语言仅含一个
  二元谓词符号~$P$ 且量词仅约束一元
  集合变元，使得 $\mModel{F} = \tuple{W, R} \in \mClass{F}$
  当且仅当在满足 $\Domain{M} = W$ 且 $\Assign{P}{M} = R$ 的结构~$\Struct{M}$ 中 $\Sat{M}{!A}$ 成立。
\end{defn}

\begin{cor}
  如果一个框架类可由公式~$!A$ 定义，那么
  相应的可达关系类可由一个一元二阶语句定义。
\end{cor}

\begin{proof}
  前面证明中的一元二阶语句~$!A'$ 具有所需的性质。
\end{proof}

作为一个例子，再次考虑公式~$\Box p \lif p$。它
定义自反性。自反性当然可由一阶语句~$\lforall[x][\Atom{Q}{x,x}]$ 定义。
但它也可以由一元二阶语句定义：
\[
\lforall[X][\lforall[x][(\lforall[y][(\Atom{Q}{x,y} \lif \Atom{X}{y})]
    \lif \Atom{X}{x})]].
\]
这当然意味着这两个语句是等价的。
下面说明如何直接验证这一点：首先假设该
二阶语句在结构~$\Struct{M}$ 中为真。由于 $x$ 和 $X$
受全称量词约束，公式的剩余部分必定对任意 $x \in W$
和集合~$X \subseteq W$ 成立，比如集合 $\Setabs{z}{Rxz}$，其中 $R =
\Assign{Q}{M}$。所以，对于任意满足 $s(x) \in W$ 和 $s(X) =
\Setabs{z}{Rxz}$ 的~$s$，我们有 $\Sat{M}{\lforall[y][(\Atom{Q}{x,y} \lif
    \Atom{X}{y})] \lif \Atom{X}{x}}$。但根据我们选取
$s(X)$ 的方式，这意味着 $\Sat{M}{\lforall[y][(\Atom{Q}{x,y} \lif
    \Atom{Q}{x,y})] \lif \Atom{Q}{x,x}}[s]$，由于前件恒真，它等价于
$\Atom{Q}{x,x}$。由于 $s(x)$ 是
任意的，我们得到 $\Sat{M}{\lforall[x][\Atom{Q}{x,x}]}$。

现在，设$\Sat{M}{\lforall[x][\Atom{Q}{x,x}]}$，并证明$\Sat{M}{\lforall[X][\lforall[x][(\lforall[y][(\Atom{Q}{x,y} \lif
        \Atom{X}{y})] \lif \Atom{X}{x})]]}$。任取一个赋值~$s$，并假设$\Sat{M}{\lforall[y][(\Atom{Q}{x,y} \lif
    \Atom{X}{y})]}[s]$。令 $s'$ 是 $s$ 的 $y$-变式，满足 $s'(y) = s(x)$；于是我们有$\Sat{M}{\Atom{Q}{x,y} \lif \Atom{X}{y}}[s']$，即$\Sat{M}{\Atom{Q}{x,x} \lif \Atom{X}{x}}[s]$。既然$\Sat{M}{\lforall[x][\Atom{Q}{x,x}]}$为真，其前件就成立，因此我们有$\Sat{M}{\Atom{X}{x}}[s]$，而这正是我们需要证明的。

既然有些可定义的框架类不是一阶可定义的，那么并非所有形如~$!A'$ 的一元二阶语句都等价于某个一阶语句。并且，不存在有效方法来判定哪些语句是等价的。
